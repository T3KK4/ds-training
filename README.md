# Data Science Training

## Overview
Training log for my transition into data science: exercises, notes and projects all built from the ground up. All code is written by me. I use an AI tutor for explanations and code review.

## Author
Triumph Okere, a registered nurse currently learning data science with a focus on healthcare data and business data.

## Structure
- `week-01/Day-01`: Python Fundamentals; mean, median and sample SD written from scratch using Python syntax and checked against Python's statistics module.
- `week-01/Day-02`: Pandas fundamentals; summarise_by_ward, input validation, tests with assertions and Pandas groupby, transform, cut and copy.

## Requirements
- Python 3.13.13
- Jupyterlab 4.6.6
- Pandas 3.1.0
- Numpy 2.5.4
- math and statistics are in Python's standard library, so no installation needed.
- Run all cells, no output from an assertion cell means all assertions passed.
